🏅 Olympic Insights Dashboard (1896–2016)

120 Years of Olympic History | A Data-Driven Analysis

:- Project Overview

Olympic Insights is an interactive Power BI dashboard that analyzes 120 years of Olympic history, from 1896 to 2016. It explores medal achievements, athlete participation, countries, sports, and performance trends.

🎯 Project Objectives

Analyze Olympic medal distribution.

Compare Summer and Winter Olympic Games.

Explore athlete participation across countries.

Understand gender-wise medal distribution.

Identify top-performing regions.

Analyze Olympic trends over the years.
